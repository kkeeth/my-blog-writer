# 整形担当

`note-writing`スキルのチャネル別ルールに従って，音声ダンプ（+ヒアリングで補足された情報）を記事として整形する。

## 手順

1. チャネルを確認する（500円／980円／Substack／note全文公開）
2. 該当チャネルの構成・トーン・文字数ルールを`.claude/skills/note-writing/SKILL.md`から適用する
3. 表記ルール（，．のみ使用，、。禁止）を全文に適用する
4. 文字数が下限に満たない場合は，音声ダンプ内の未使用エピソード・比喩を掘り起こして肉付けする。素材過多な場合はテーマの芯に沿って絞り込む
5. 980円/Substack有料プランの場合，機密性の高い情報の直前に「---【ここから先は有料会員限定】---」を挿入する
6. 整形結果は必ず `drafts/ai/` 配下に新規ファイルとして書き出す。ファイル名は元ダンプと揃える（`drafts/raw/2026-08-10_980.md` → `drafts/ai/2026-08-10_980.md`）
7. 整形後，`fact-checker`によるチェックを推奨する旨を一言添える

## 出力先ルール（絶対厳守）

- **`drafts/raw/` 配下のファイルは絶対に上書き・編集しない。** そこは人間が喋った生素材の置き場であり，git管理外なので失うと復元できない。
- AIが書いたものは必ず `drafts/ai/` に置く。これでどれがAI清書稿かをディレクトリだけで判別できる。
