# note-writing

KEETHさんの音声ダンプを各チャネル向けの記事に仕上げるための共通ルール。ネタ出し（週次執筆プラン）はCowork側で行うため，ここでは扱わない。

## チャネル一覧

- **500円**「真面目な本音の共有場」：気づき・体験・本音を誠実に共有
- **980円**「表では言えない凡人の本音」：表では言いにくい率直な意見・解釈
- **Substack**：独自トーンのエッセイ。個人のストーリーや専門性を前面に
- **note全文公開（無料）**：集客用・軽めの気づき系

## チャネル判定について

KEETHさんがチャネルを決めきれていないことは多い。**チャネルの指定がないまま整形を依頼された場合は，勝手に決め打ちせず，ダンプ内容から最適なチャネルを評価して提案する**（`hearing-agent`がヒアリングと同時に担当）。

チャネルが明示されている場合は原則それに従う。ただし明らかにミスマッチな場合（例：家族背景や他者への率直な批判が中心のダンプを「全文公開」で依頼された等）は，従いつつも一言だけ別チャネル案を添える。

### 判定シグナル

以下を上から順に見て，最初に強く当てはまったチャネルを第一候補にする。

1. **980円「表では言えない凡人の本音」**
   - 個人が特定されうる具体的なエピソード，前科・宗教・家族背景などの機密性が高い情報が含まれる
   - 業界・他者・世間の風潮への率直な批判や，表では言いにくい本音が芯にある
   - 「本当は〜と思っている」「言えないけど」といった反転構造が素材にある
2. **Substack**
   - 技術・キャリア・コーチングなど**専門性**を語れる素材があり，個人のストーリーと織り交ぜられる
   - 踏み込んだ本音というより，読み物・エッセイとしての読み応えが主軸
   - パーソナルブランディング（KEETHさんという人物への興味）につながる内容
3. **500円「真面目な本音の共有場」**
   - 誠実な気づき・体験の共有が中心で，機密性は高くない
   - 等身大の失敗談・学びなど，読者が共感しやすい温度
4. **note全文公開（無料）**
   - 気づきが1つに絞れる軽い話で，誰が読んでも分かる
   - 機密性・専門性ともに低く，メンバーシップへの導線として置ける

### 素材量による補正

ダンプの分量も判断材料にする。素材が薄い（800〜1200字程度にしかならない）場合は，内容が980円寄りでも全文公開を提案し，濃い部分は次回の有料記事に回す選択肢を示す。逆に素材が非常に濃く長い場合は，500円ではなく980円/Substackを提案する。

### 提案の出し方

- 第一候補と理由を2〜3行で述べる
- 第二候補があれば「◯◯にするならこの部分を軸にする」まで添える
- 最終決定はKEETHさんに委ねる。返事を待たずに整形を始めない

## 整形前のヒアリングについて（最優先）

KEETHさんは感情・評価（好き，感動した，良かった，モヤっとした等）を語る一方で，その理由や背景（具体的に何が，なぜそう感じさせたか，どんな経験・価値観と結びついているか）が言語化されないまま音声ダンプに残っていることが多い。

「整形して」を受け取ったら，すぐに整形せず，まず音声ダンプ内で理由・背景が言語化されていない感情/評価表現を1〜3箇所ピックアップし，「なぜそう感じたか」を尋ね返す一言リアクションを返すこと（`hearing-agent`の担当）。ユーザーから追加の説明が返ってきたら，それを素材に加えたうえで整形する。

音声ダンプの時点ですでに理由・背景が十分語られている場合は，聞き返さずそのまま整形してよい。

本人が不在の自動実行の場合は，聞き返さずそのまま整形する。

## 表記ルール（全チャネル・全記事共通・絶対厳守）

句読点は「、」「。」を一切使わず，必ず全角カンマ「，」と全角ドット「．」を使う。見出し・本文問わず全文に適用する。通常の句読点で書いてしまった場合は，すぐに全文を「，」「．」に置き換えて再提出する。

## チャネル別ルール

### note 500円プラン

- 構成：①共感を引く導入 → ②本音・気づき（h2見出し2〜3個）→ ③まとめ or 問いかけ
- トーン：等身大，誠実，改行多め
- 文字数：1500〜2000字目安

### note 980円プラン

- 構成：①引っかかりのある問題提起 → ②「でも本当は〜」の反転 → ③論理で包んだ本音（h2見出し2〜4個）→ ④締め
- トーン：率直・直球，炎上しないロジックを添える，「個人の解釈です」を自然に入れる
- 文字数：2500〜4000字目安
- 有料会員限定として書く場合，無料で読める前半（共感を引く一般論・問題提起まで）と有料部分（個人の具体的な経験・踏み込んだ本音）の間に「---【ここから先は有料会員限定】---」を挿入する。区切りの位置は，個人が特定されうる具体的なエピソードや前科・宗教・家族背景などの機密性が高い情報が出てくる直前が目安

### Substack

- 構成：①個人的なエピソード・フックとなる導入 → ②本題（h2見出し2〜3個，ストーリーテリング＋専門性を織り交ぜる）→ ③示唆・学び → ④締め（次号への軽い予告可）
- トーン：note980円プランよりエッセイ的・パーソナルブランディング寄り。読み応えと個性を両立
- 文字数：2000〜3500字目安
- 有料プラン想定時は980円プランと同様に無料/有料の区切りを入れる

### note全文公開（無料）

- 構成：①身近な導入 → ②気づき1つに絞った本題（h2見出し1〜2個）→ ③軽い締め＋メンバーシップへの自然な誘導
- トーン：誰でも読める平易な語り口，軽め・短め
- 文字数：800〜1200字目安

## 文字数について

指定文字数の下限に届かない場合は，内容を薄める加筆ではなく，音声ダンプの中にある未使用のエピソード・具体例・比喩を掘り起こして肉付けする。逆に素材が豊富な場合は，テーマの芯に沿って厳選し，冗長にならないよう絞り込む。

## ファクトチェックについて

本文中に歴史的事実・数値・作品の設定など検証可能な事実が含まれる場合は，Web検索で確認し，誤りがあれば訂正する（`fact-checker`の担当）。個人の体験談・感情・解釈など検証不可能なものはそのまま扱う。外部情報を参照した場合は，回答の最後にSourcesセクションを付ける。
