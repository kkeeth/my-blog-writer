# note-writing

KEETHさんの音声ダンプを各チャネル向けの記事に仕上げるための共通ルール。ネタ出し（週次執筆プラン）はCowork側で行うため，ここでは扱わない。

チャネルの一覧と位置づけは `CLAUDE.md` の「発信チャネル」を正とする。

## 表記ルール（全チャネル・全記事共通・絶対厳守）

句読点は「、」「。」を一切使わず，必ず全角カンマ「，」と全角ドット「．」を使う。見出し・本文問わず全文に適用する。通常の句読点で書いてしまった場合は，すぐに全文を「，」「．」に置き換えて再提出する。

**半角の「,」「.」も使わない。**全角「，」「．」と見分けがつきにくいので，書き終えたら半角が混入していないか必ず確認する。URLやファイル名，箇条書きの番号（`1. `）に含まれる半角ドットは対象外。

## 英数字の表記ルール（全チャネル・全記事共通・絶対厳守）

**アルファベットの語（英単語・固有名詞・略語）の前後には，半角スペースを1つ入れる。**

- 例：「ひたすら YouTube を見て」「気づいたら X を見ていた」「NBA 選手」「Web 漫画」「QR コード決済」「感じて OK だし」
- **数字だけの語は対象外。**「5分」「1〜2時間」「夕方4時」はそのまま
- 全角の括弧・句読点に接する位置には入れない（「（Instagram など）」「YouTube，」）
- 行頭・行末には入れない
- URL・ファイル名・コード内の英字は対象外

## 詳細ルールの置き場

必要な方だけを読むこと。両方まとめて読まない。

| 読むファイル | 内容 | 読む担当 |
| --- | --- | --- |
| `references/channel-selection.md` | 判定順序，ズレ判定，除外ルール，判定シグナル，素材量による補正，提案の出し方 | `hearing-agent`（チャネル未指定のときのみ） |
| `references/channel-templates.md` | 5チャネルの書式・文体・文字数・有料区切り | `formatter`（整形するチャネルが決まってから） |
| `references/zure-sample.md` | 「ズレたままでいる」の文体見本（公開済み記事の全文と読み取りどころ） | `formatter`（`_zure` 案件のときのみ） |

`fact-checker` はいずれも読む必要がない。上の表記ルールだけ守ればよい。

## 各工程のルールの持ち主

工程ごとの手順は各エージェント定義が持つ。ここには書かない。

- ヒアリング（感情・評価の理由を問い返す）→ `.claude/agents/hearing-agent.md`
- 整形 → `.claude/agents/formatter.md`
- ファクトチェック → `.claude/agents/fact-checker.md`
