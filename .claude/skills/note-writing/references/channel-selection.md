# チャネル判定

`hearing-agent`専用。チャネル未指定のまま整形を依頼されたときに読む。

KEETHさんがチャネルを決めきれていないことは多い。**チャネルの指定がないまま整形を依頼された場合は，勝手に決め打ちせず，ダンプ内容から最適なチャネルを評価して提案する**。

チャネルが明示されている場合は原則それに従う。ただし明らかにミスマッチな場合（例：家族背景や他者への率直な批判が中心のダンプを「全文公開」で依頼された等）は，従いつつも一言だけ別チャネル案を添える。

## 判定順序

1. **まず「ズレ判定」を行う**（下記）。通れば無条件で note マガジン「ズレたままでいる」とし，以降の判定はしない。
2. 通らなければ除外ルールを見たうえで，判定シグナル（980円 → Substack → 500円 → 全文公開）に落とす。

「ズレたままでいる」は他の4チャネルと判定軸が異なる（機密性・専門性・素材の濃さでは測らない）ため，判定の最初に単独で置く。

## ズレ判定

以下を**すべて満たす**場合のみ「ズレたままでいる」とする。ひとつでも欠けたら既存4チャネルの判定に落とす。

- 合理的な理由だけでは説明がつかない（説明がついてしまうならノウハウ記事であり，このチャネルではない）
- 「みんな〜しがちだが」で書き出せない（書き出せるなら逆張りであり，このチャネルではない）
- 実際に継続している。金・手間・気まずさのいずれかのコストを払っている

## 除外ルール（判定シグナルより優先）

判定シグナルを見る前に，まずここで候補から落とす。

- **Substackにビジネス・プロダクト論・組織論・売上や数字まわりの話題は載せない。** KEETHさんはSubstackを「個人のストーリーと専門性を語る場」と位置づけており，ビジネス的な観点は意図的に持ち込まない方針。したがって専門性が高くてもこれらの主題はSubstack候補から外し，note側（500円/980円/全文公開）で検討する。真面目な話・硬めの話ほどnoteに置き，メンバーシップへのフックとして機能させる（2026-08-24 本人確認）。

## 判定シグナル

以下を上から順に見て，最初に強く当てはまったチャネルを第一候補にする。

1. **980円「表では言えない凡人の本音」**
   - 個人が特定されうる具体的なエピソード，前科・宗教・家族背景などの機密性が高い情報が含まれる
   - 業界・他者・世間の風潮への率直な批判や，表では言いにくい本音が芯にある
   - 「本当は〜と思っている」「言えないけど」といった反転構造が素材にある
2. **Substack**
   - 技術・キャリア・コーチングなど**専門性**を語れる素材があり，個人のストーリーと織り交ぜられる
   - 踏み込んだ本音というより，読み物・エッセイとしての読み応えが主軸
   - パーソナルブランディング（KEETHさんという人物への興味）につながる内容
3. **500円「真面目な本音の共有場」**
   - 誠実な気づき・体験の共有が中心で，機密性は高くない
   - 等身大の失敗談・学びなど，読者が共感しやすい温度
4. **note全文公開（無料）**
   - 気づきが1つに絞れる軽い話で，誰が読んでも分かる
   - 機密性・専門性ともに低く，メンバーシップへの導線として置ける

## 素材量による補正

ダンプの分量も判断材料にする。素材が薄い（800〜1200字程度にしかならない）場合は，内容が980円寄りでも全文公開を提案し，濃い部分は次回の有料記事に回す選択肢を示す。逆に素材が非常に濃く長い場合は，500円ではなく980円/Substackを提案する。

## 提案の出し方

- 第一候補と理由を2〜3行で述べる
- 第二候補があれば「◯◯にするならこの部分を軸にする」まで添える
- 最終決定はKEETHさんに委ねる。返事を待たずに整形を始めない
