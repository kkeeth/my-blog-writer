# チャネル別テンプレート

`formatter`専用。整形するチャネルが決まってから読む。

## note 500円プラン

- 構成：①共感を引く導入 → ②本音・気づき（h2見出し2〜3個）→ ③まとめ or 問いかけ
- トーン：等身大，誠実，改行多め
- 文字数：1500〜2000字目安

## note 980円プラン

- 構成：①引っかかりのある問題提起 → ②「でも本当は〜」の反転 → ③論理で包んだ本音（h2見出し2〜4個）→ ④締め
- トーン：率直・直球，炎上しないロジックを添える，「個人の解釈です」を自然に入れる
- 文字数：2500〜4000字目安
- 有料会員限定として書く場合，無料で読める前半（共感を引く一般論・問題提起まで）と有料部分（個人の具体的な経験・踏み込んだ本音）の間に「---【ここから先は有料会員限定】---」を挿入する。区切りの位置は，個人が特定されうる具体的なエピソードや前科・宗教・家族背景などの機密性が高い情報が出てくる直前が目安

## Substack

- 構成：①個人的なエピソード・フックとなる導入 → ②本題（h2見出し2〜3個，ストーリーテリング＋専門性を織り交ぜる）→ ③示唆・学び → ④締め（次号への軽い予告可）
- トーン：note980円プランよりエッセイ的・パーソナルブランディング寄り。読み応えと個性を両立
- 文字数：2000〜3500字目安
- 有料プラン想定時は980円プランと同様に無料/有料の区切りを入れる

## note全文公開（無料）

- 構成：①身近な導入 → ②気づき1つに絞った本題（h2見出し1〜2個）→ ③軽い締め＋メンバーシップへの自然な誘導
- トーン：誰でも読める平易な語り口，軽め・短め
- 文字数：800〜1200字目安

## 文字数について

指定文字数の下限に届かない場合は，内容を薄める加筆ではなく，音声ダンプの中にある未使用のエピソード・具体例・比喩を掘り起こして肉付けする。逆に素材が豊富な場合は，テーマの芯に沿って厳選し，冗長にならないよう絞り込む。
