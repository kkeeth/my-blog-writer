# チャネル別テンプレート

`formatter`専用。整形するチャネルが決まってから読む。

## note 500円プラン

- 構成：①共感を引く導入 → ②本音・気づき（h2見出し2〜3個）→ ③まとめ or 問いかけ
- **文体：だ・である調。断言口調で書く。ですます調にしない**
- トーン：等身大，誠実，改行多め
- 文字数：1500〜2000字目安

## note 980円プラン

- 構成：①引っかかりのある問題提起 → ②「でも本当は〜」の反転 → ③論理で包んだ本音（h2見出し2〜4個）→ ④締め
- **文体：だ・である調。断言口調で書く。ですます調にしない**
- **一人称は「自分」。**「僕」にしない（「僕」は「ズレたままでいる」の一人称）
- **「ズレたままでいる」の文体を持ち込まない。**一文だけの段落を積んで余韻で落とすような詩的・エッセイ的な書き方はしない。段落として論を進め，断言で押し切る
- トーン：率直・直球，炎上しないロジックを添える，「個人の解釈です」を自然に入れる
- 文字数：2500〜4000字目安
- 有料会員限定として書く場合，無料で読める前半（共感を引く一般論・問題提起まで）と有料部分（個人の具体的な経験・踏み込んだ本音）の間に「---【ここから先は有料会員限定】---」を挿入する。区切りの位置は，個人が特定されうる具体的なエピソードや前科・宗教・家族背景などの機密性が高い情報が出てくる直前が目安

## Substack

- 構成：①個人的なエピソード・フックとなる導入 → ②本題（h2見出し2〜3個，ストーリーテリング＋専門性を織り交ぜる）→ ③示唆・学び → ④締め（次号への軽い予告可）
- トーン：note980円プランよりエッセイ的・パーソナルブランディング寄り。読み応えと個性を両立
- 文字数：2000〜3500字目安
- 有料プラン想定時は980円プランと同様に無料/有料の区切りを入れる

## note全文公開（無料）

- 構成：①身近な導入 → ②気づき1つに絞った本題（h2見出し1〜2個）→ ③軽い締め＋メンバーシップへの自然な誘導
- **文体：記事ごとに変わる。ですます調のときもである調のときもあるため，指定がなければKEETHさんに確認してから書く**（メンバーシップの2チャネルと違い，である調に固定しない）
- トーン：誰でも読める平易な語り口，軽め・短め
- 文字数：800〜1200字目安

## note マガジン「ズレたままでいる」（無料エッセイ連載）

合理では説明できないこだわりの記録。**他の4チャネルとは書式・文体・文字数のすべてが異なる**ので，上のルールを流用しないこと。

### 書式（絶対厳守）

- **見出しを一切使わない。** H1・H2・太字の小見出し・章立て，すべて不可
- **箇条書きにしない。** 列挙したい内容も文章に流し込む
- 「はじめに」「まとめ」「おわりに」等の構造ラベルを付けない
- 挨拶・自己紹介から始めない。本題から入る
- タイトルにナンバリングや連載名の接頭辞を付けない。中身だけを書く
- **締めの署名・定型句を付けない。**「ではでは．」などで終わらせないこと。`zure-sample.md` の見本記事は末尾に「ではでは．」が付いているが，**これは連載の定型ではないので倣わない**（`published/` の実記事はいずれも付けずに終わっている）。本文は最後の一行で落としてそのまま終える
- **本文末尾に下記の固定フッターを置く**（次の節）

### 本文末尾の固定フッター（絶対厳守）

記事本文の最後に，区切り線を含めて以下をそのまま置く。**このマガジンの全記事に付ける。**

```
---

仕事や家庭のこと，ちょっと表では言えない話などを[メンバーシップ](https://note.com/clown0082/membership)のほうで書いています．こんな感じで．
```

メンバーシップURLの正はここ。他のファイルに同じURLを重複して持たせない。

`formatter` が付ける「ダンプに無い内容を補った箇所」等の作業メモは，**このフッターのさらに後ろ**に置く。フッターは記事本文の一部として扱う。

### 文体

- だ・である調。一人称は「僕」
- 音声ダンプの語彙と言い回しをできるだけ残す。平均的で滑らかな文章に均さない
- オチで教訓を言わない。「つまり人生とは」に着地させない
- 抽象語ではなく数字と固有名詞を使う（「こだわった」ではなく「3ヶ月悩んで6万円のドアにした」）
- 自嘲を混ぜる。美学が破綻した瞬間の記録は必ず残す
- 構成は「観察を積む → 途中で結論を出さない → 最後に短い一行で落とす」
- もっともらしくない理由（面倒だった等）を先に出し，そのあとで本音に降りる
- 自分に不利な事実（回数が少ない，覚えていない，怪しまれた等）を削らない

### 文字数

**指定しない。** 3行で終わってもよいし3000字になってもよい。書き終わったところが終わり。字数を埋めるために説明を足さない。長いからといって削らない。**下の「文字数について」の節はこのチャネルには適用しない。**

### このチャネルでの`formatter`の振る舞い

- **完成品を出さない。** 叩き台までとし，書き手が手を入れる余地を残す
- 音声ダンプに無い内容を推測で補った箇所は，本文の後に箇条書きで明示する
- **文体の見本は `references/zure-sample.md` を必ず読む。**書式・文体に迷ったらこの記事に寄せる

## 文字数について

**「ズレたままでいる」を除く4チャネルに適用する。**

指定文字数の下限に届かない場合は，内容を薄める加筆ではなく，音声ダンプの中にある未使用のエピソード・具体例・比喩を掘り起こして肉付けする。逆に素材が豊富な場合は，テーマの芯に沿って厳選し，冗長にならないよう絞り込む。
